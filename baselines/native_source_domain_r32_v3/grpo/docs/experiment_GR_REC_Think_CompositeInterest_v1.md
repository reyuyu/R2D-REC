## Motivation

This Think-only ablation tests whether a balanced downstream Beam32 and structured-interest reward can resist the late-stage information collapse observed in earlier Think training. ExactClamp, NoThink, bridge, teacher, explicit diversity reward, and length reward are excluded so the composite reward remains attributable.

## Shared interest parser

Gold and candidate CoT use the same extract_interest_units function in the existing think_diagnostics module. It requires the canonical Interest Summary heading and numbered bullets. Missing headings and empty sections return parser_success false; the parser never falls back to treating the whole CoT as an interest.

Each unit includes order, raw text, normalized text, evidence SIDs, and SIDs grounded in the current user prompt. Normalization removes bullet numbers, SID serialization, Markdown emphasis, template markers, and redundant whitespace without deleting semantic words.

## Pair metric

S_text is character-bigram multiset F1. It is deterministic, Chinese-friendly, dependency-free, and less dependent on whitespace than word splitting.

S_evidence is set F1 over grounded SID evidence. Both empty, one empty, or disjoint evidence returns zero. Only SIDs present in the current prompt can receive evidence credit.

S_pair = 0.7 * S_text + 0.3 * S_evidence.

Candidate and Gold interests are matched with an exact deterministic dynamic-programming maximum-weight one-to-one matcher. A pair is valid when S_pair is at least 0.60. Duplicates cannot consume the same Gold item twice.

K is the valid match count. Coverage is K / N_gold and monitor-only precision is K / N_pred.

Coverage tier T:
- K = 0: 0
- 0 < coverage <= 0.25: 0.20
- 0.25 < coverage <= 0.50: 0.45
- 0.50 < coverage < 1: 0.70
- coverage = 1: 1.00

For K greater than zero, Q = clip((mean matched similarity - 0.60) / 0.40, 0, 1); otherwise Q = 0.

U_cot = 0.8 * T + 0.2 * Q.

## Beam and composite reward

For finite positive raw Beam reward:

U_beam = clip(log(1 + R_beam) / log(17), 0, 1).

Invalid, non-finite, negative, and zero rewards map to zero. Values 16 and above saturate at one.

R_total = 0.60 * U_beam + 0.40 * U_cot.

Only R_total would enter standard G4 GRPO advantage:

A_i = (R_total_i - mean_G4) / (population_std_G4 + 1e-4).

Exactly equal G4 rewards produce exactly zero advantages. ExactClamp and separate channel normalization are not used.

## CPU quality audit

A deterministic domain/interest-count stratified sample of 128 parser-valid Gold groups was tested.

Mean U_cot:
- identity: 0.9577
- reorder: 0.9577
- drop one: 0.5070
- drop half: 0.3825
- one interest: 0.5575
- duplicate one: 0.5575
- extra unmatched: 0.9577
- remove SID: 0.8500
- wrong SID: 0.8500
- light lexical edit: 0.8813

Identity equals reorder and adding unmatched interests does not improve K. Removing or replacing evidence lowers the score. Duplicate interests cannot increase coverage. The one-interest mean can exceed drop-one because the sample intentionally includes Gold sets with one or two units; the per-example tier still follows the exact coverage definition.

On 1192 historical Think candidates, candidate parser success was 95.64% and joined Gold parser success was 94.30%, but nonzero match rate was 0%. U_cot was consequently constant zero, so its correlations with length, Raw N, Grounded N, grounding coverage, and U_beam are undefined. This is a substantive pre-training risk: character-bigram similarity at threshold 0.60 is too strict for those historical Gold/candidate lexical differences. The requested formula is preserved rather than tuned post hoc.

Metric runtime was 1.24 ms per candidate and 4.97 ms per G4 on CPU, far below Beam32 cost.

Representative tradeoffs:
- Beam 0 plus perfect CoT: 0.4000
- Beam 0.5 plus bad CoT: 0.0859
- Beam 2 plus bad CoT: 0.2327
- Beam 8 plus bad CoT: 0.4653
- Beam 16 plus bad CoT: 0.6000

## Data leakage guard

The read-only adapter adds Gold only after records are loaded. It deep-copies source records and asserts the model prompt is byte-identical. Tests verify Gold text is absent from the model input prompt. Gold is not supplied to Beam prompts, generation context, or teacher forcing.

Because provenance is incomplete, the adapter fails closed before building a formal dataset. No runnable training runner exists in this code point.

## Known risks and next gate

Two independent blockers exist:
1. 91 of 1549 Think groups lack safely joinable Gold CoT.
2. The frozen lexical metric produced zero nontrivial historical matches at threshold 0.60.

Formal GPU work requires an auditable source for all 91 missing Gold references and a separately approved metric calibration decision. Neither may be repaired with generated references, candidate-derived references, fuzzy matching, or an unreviewed threshold change.
