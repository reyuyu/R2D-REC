# 1. 已知数据事实：必须作为设计依据

以下数字来自当前已完成的 43,448 条懂推荐纯数据诊断。

## 1.1 四域 Gold hierarchy 与 target-domain history 的 overlap

| Domain | Gold-SA in H | Gold-SAB in H | Gold-SABC in H |
|---|---:|---:|---:|
| Video | 39.17% | 5.90% | 0.65% |
| Product | 49.68% | 20.04% | 15.29% |
| Ad | 68.13% | 29.89% | 12.03% |
| Living | 44.64% | 23.77% | 12.90% |

直接含义：

```text

大多数 future-SA 不在 history。

Ad:

Living:
history overlap 中等，

```

|---|---:|---:|

## 1.3 History 长度与 fragmentation

全部懂推荐：

```text
H median = 170
mean     = 174.36
P95      = 308
P99      = 377
max      = 537
81.50% samples have H > 100
```

长 History 本身不是问题。

Video 的关键现象：

```text
H 51–100:
Gold-SA in H                    = 29.89%
Top10 | Gold-SA already in H    = 85.96%

H > 400:
Gold-SA in H                    = 68.16%
Top10 | Gold-SA already in H    = 52.55%
```

同一个 `H=201–300`：

| N_SA | Top10 all | Top10 \| Gold-SA in H |
|---|---:|---:|
| 21–40 | 43.09% | 87.11% |
| 41–80 | 31.49% | 69.58% |
| 81–120 | 23.90% | 46.60% |

结论：

> 真正的问题更接近 unique-SA fragmentation / ranking dilution，

所以本轮：

```text

禁止因为 H>某阈值直接删除样本
```

## 1.5 Behavior × hierarchy 的证据强度并不相同

进一步对全部 43,448 条懂推荐数据做去重归因后，发现不同历史行为对
`SA → SAB → SABC` 的预测价值差异非常大。

Video：

| Behavior | 样本覆盖率 | Gold-SA 条件命中 | Gold-SAB 条件命中 | Gold-SABC 条件命中 | SABC 可复用归因 |
|---|---:|---:|---:|---:|---:|
| 深度观看 | 87.88% | 37.19% | 4.99% | 0.57% | 74.30% |
| 普通观看 | 57.59% | 3.41% | 0.14% | 0.01% | 0.47% |

Video 其余 SABC 归因大致为：

```text
长播  11.36%
点赞   6.09%
收藏   2.79%
关注   2.36%
```

其他域主要结论：

```text
Product:
浏览贡献主要 SABC 证据；
加购低频，但单位证据效率高。

Ad:
点击贡献主要 SABC 证据；
深度转化覆盖较小，但单位证据效率更高。

Living:
关注贡献 94.28% 的可复用 SABC 归因；
首次打赏 / 普通打赏更像 SA 级方向信号，
从 SA 到 SABC 迅速衰减。
```

因此：

> History competitor 的“重要性”不能只用出现次数衡量。
> 同一个行为在 A/B/C 三层也不能使用同一权重。

本轮由此增加一个新的设计约束：

```text
S1:
仍保持纯 novelty-aware TopK，行为不参与，保证单变量。

S2:
History-Competitive FDR 必须升级为
Behavior-Conditioned + Hierarchy-Aware evidence，
不再使用纯 frequency 作为唯一 hard-negative 排序。
```

同时必须注意：

```text
高行为证据 competitor
可能是未标注但合理的 future mode，
不能因为它不是当前 row gold 就被过强压制。
```

所以 behavior evidence 在 S2 中既用于：

1. 判断哪些 history mode 真正具有层级证据；
2. 调整 pairwise margin / sampling；
3. 对强证据的 plausible competitor 做保护，避免 false-negative collapse。

# 5. S1：Novelty-Aware Hierarchical Top16 / Top32 Loss

这是第一优先正式实验。

## 5.1 样本层级类型

对当前训练 row 的 GT：

```text
y* = (a*, b*, c*)
```

解析当前 **target-domain history**。

定义：

### T0 — Novel-SA

```text
a* not in history_A
```

### T1 — SA seen, SAB novel

```text
a* in history_A
(a*, b*) not in history_AB
```

### T2 — SAB seen, exact SID novel

```text
(a*, b*) in history_AB
(a*, b*, c*) not in history_ABC
```

### T3 — Exact replay

```text
(a*, b*, c*) in history_ABC
```

必须断言：

```text
T0/T1/T2/T3 mutually exclusive
T0+T1+T2+T3 = every recommendation training row
```

---

# 6. 为什么 novelty type 直接决定 A/B/C auxiliary emphasis

直觉：

```text
T0:
第一次新决策就在 A
→ A routing 最重要

T1:
A 已有历史证据
第一次新决策在 B
→ B 最重要

T2:
AB 已有历史证据
第一次新决策在 C
→ C 最重要

T3:
完整 SID 已出现
→ 更偏 continuation / exact sharpening
```

第一版不做复杂 domain 手调。

使用统一 novelty matrix，让四域因自己的 T0/T1/T2/T3 分布自然产生不同有效权重。

建议默认：

| Type | w_A | w_B | w_C |
|---|---:|---:|---:|
| T0 | 0.50 | 0.30 | 0.20 |
| T1 | 0.20 | 0.50 | 0.30 |
| T2 | 0.15 | 0.25 | 0.60 |
| T3 | 0.15 | 0.25 | 0.60 |

要求：

```text
each row weights sum to 1.0
```

这些权重只作用于 **新增 Top-K auxiliary**。

禁止第一版用它重写已有 `L_rec_v42`。

# 7. Top-K boundary 的候选集合

这是实现中最重要的安全边界之一。

## 7.1 不允许把所有“未见 tuple”直接当成错误 SID

Itemic hierarchy 需要保留泛化能力。

因此：

```text
unseen train tuple
!=
guaranteed invalid SID
```

本轮不得创建 generation-time legal-SID mask。

不得把 train catalog 当作完整世界。

---

## 7.2 Top-K auxiliary 使用“安全负例 catalog”

沿用 V4.2/FDR 已有的 train-only candidate catalog 语义。

建议：

```text
A negative candidates:
observed train candidate A for target domain

B negative candidates:
observed train B under current GT a*

C negative candidates:
observed train C under current GT (a*, b*)
```

然后减去当前 group 的 known positive set。

用途仅为：

```text
ranking auxiliary / safe negative boundary
```

绝对禁止：

```text
用该 catalog mask model output
把未观察 tuple 判非法
```

---

# 8. Positive sets

沿用当前 group-level positive set。

定义：

```text
A+ = all positive A in same prompt group

B+(a*) =
all positive B whose positive SID prefix A == a*

C+(a*,b*) =
all positive C whose positive SID prefix AB == (a*,b*)
```

要求：

```text
known positive token never enters negative boundary set
```

---

# 9. Top16 / Top32 boundary loss

对层级 `l ∈ {A,B,C}`：

- `z_l[p]`：当前 teacher-forced context 下 positive token logit；
- `N_l`：安全 negative token set；
- `q^-_{l,K}`：`N_l` 中第 K 高 negative logit。

定义：

\[
L_{l,K}
=
\frac{1}{|P_l|}
\sum_{p\in P_l}
\operatorname{softplus}
\left(
\frac{q^-_{l,K}+m_l-z_l[p]}{\tau_l}
\right)
\]

其中：

```text
P_A = A+
P_B = B+(a*)
P_C = C+(a*, b*)
```

teacher-forced context 必须严格为：

```text
A logits: context = x
B logits: context = x, a*
C logits: context = x, a*, b*
```

禁止：

```text
拿 GT-a context 的 B logits 冒充 wrong-a candidate 的 B probability
拿 GT-ab context 的 C logits 冒充 wrong-prefix candidate 的 C probability
```

# 10. Top16 / Top32 组合

第一版默认：

```text
alpha_16 = 0.35
alpha_32 = 0.65

margin_A = 0.10
margin_B = 0.10
margin_C = 0.10

temperature = 1.0
```

每层：

\[
L_l
=
\alpha_{16}L_{l,16}
+
\alpha_{32}L_{l,32}
\]

样本：

\[
L_{\text{hier-topk}}
=
w_A L_A
+
w_B L_B
+
w_C L_C
\]

默认：

```text
lambda_topk = 0.10
```

必须全部配置化。

---

# 11. Candidate 数不足 K 时的规则

如果某层安全 negative candidate 数：

```text
|N_l| < K
```

则该 `L_{l,K}` **直接 skip**。

理由：

```text
若合法安全 competitor 本身不足 K，
则“TopK boundary”没有足够定义。
```

禁止：

```text
用随机 vocab token 补满
用 unseen tuple 补满
复制 negative 补满
```

记录：

```text
top16_active_rate_A/B/C
top32_active_rate_A/B/C
```

# 14. S2：Behavior-Conditioned History-Competitive FDR

只有 S1 有正向结果后才做正式训练。

Codex 可以在第一次实现中把模块写好并默认关闭。

S2 的目标仍然是：

> 直接针对 high-N_SA History 中真正会抢 Beam slot 的历史 mode。

但根据新的 behavior allocation 统计，**不允许再把 raw frequency 当作唯一 history evidence**。

---

## 14.1 Hierarchy-specific behavior reliability

必须从 **V4.2-A 实际 train split** 重新估计：

```text
r[d, behavior, level]
```

其中：

```text
d     ∈ {video, prod, ad, living}
level ∈ {A, AB, ABC}
```

第一版建议使用 train-only 的平滑 enrichment / log-odds，而不是直接把全量数据的归因百分比硬编码为权重。

例如：

\[
r_{d,b,l}
=
\operatorname{clip}
\left(
\log
\frac{p(\mathrm{GoldHit}_l\mid d,b)+\epsilon}
     {p(\mathrm{GoldHit}_l\mid d)+\epsilon},
-r_{\max},r_{\max}
\right)
\]

要求：

```text
train split only
Laplace/Beta smoothing
clip extreme low-frequency weights
record support count
```

如果某行为样本过少，则：

```text
shrink toward domain-level neutral weight
```

禁止直接使用 validation/test 统计。

---

## 14.2 Candidate behavior evidence

对某个 hierarchy candidate `u`，定义其在 history 中的层级行为证据：

\[
E_l(u)
=
\sum_b
r_{d,b,l}
\log(1+n_b(u,l))
\]

其中：

```text
n_b(u,l)
=
candidate u 在 behavior=b 的 target-domain history 中
以该 hierarchy level 出现的次数
```

使用 `log(1+n)` 是为了：

```text
保留重复行为 evidence
但避免单纯出现次数线性爆炸。
```

该 evidence 只参与 S2 ranking auxiliary。

禁止：

```text
作为新的 hard label
作为 generation-time mask
直接替代 model logits
```

---

## 14.3 为什么必须分 A / AB / ABC

新的数据已经证明：

```text
Video 普通观看:
A 仍有少量方向信号，
到 AB/ABC 几乎消失。

Video 深度观看:
越到精确层级越占主导。

Living 打赏:
主要是 A-level 方向信号。

Living 关注:
对 ABC 极强。
```

所以必须分别计算：

```text
E_A
E_AB
E_ABC
```

禁止：

```text
one behavior weight for all SID levels
```

---

## 14.4 Positive support strength

当前 GT 在某层若已经出现在 history，计算：

```text
E_pos_l
```

若 GT 该层为 novel：

```text
E_pos_l = 0
```

S2 可以用 `E_pos_l` 轻量放大 pairwise margin：

\[
m_l^{pair}
=
\operatorname{clip}
\left(
m_l
+
\gamma_{pos}\,\hat E_{pos,l}
-
\gamma_{neg}\,\hat E_{neg,l},
m_{min},m_{max}
\right)
\]

其中 `\hat E` 为 domain/level 内归一化后的 evidence。

意义：

```text
Gold 受到高质量行为强支持
→ 可以更有信心 sharpen。

competitor 受到高质量行为强支持
→ 它更可能是合理但未标注 future，
  margin 应更小，避免 false-negative collapse。
```

这比：

```text
强行为 competitor -> 更猛烈往下压
```

更符合 Pass@64 的 multi-plausible 推荐目标。

---

## 14.5 A-level history competitor

候选：

```text
history A
minus A+
```

候选优先级不再只按：

```text
raw frequency
```

而按组合 score：

\[
S_A(u)
=
\eta_f\,\widetilde{\log(1+count(u))}
+
\eta_e\,\widetilde{E_A(u)}
+
\eta_z\,\widetilde{z_A(u)}
\]

其中：

```text
count(u) : history count
E_A(u)   : behavior evidence
z_A(u)   : 当前模型 teacher-forced A logit（可选）
```

S2 第一版建议：

```text
eta_f = 0.35
eta_e = 0.45
eta_z = 0.20
```

## 14.6 Novel-SA 情况

若：

```text

```

```text

```


> 把所有历史兴趣压死。

而是：

> 让 novel gold SA 能进入高概率竞争区，同时保留真正有证据的历史 mode。


C：

```text
排除 C+(a*,b*)
```

然后继续复用严格 First-Divergence 逻辑。

# 16. S3：Video Multi-A Coverage

只有 S1 / S2 已经证明方向正确后才正式打开。

背景：

```text
Video multi-gold history groups
often have multiple distinct positive SA modes
```

现有：

\[
-\log\sum_{a\in A^+}P(a)
\]

允许一个 positive A 吃掉大部分 positive mass。

为了 Beam32 multi-mode coverage，新增一个非常保守的二模态约束。

---

## 16.1 Second-positive A boundary

仅对：

```text
target_domain == video
|A+| >= 2
```

取 positive A logits 中第二高：

\[
s^+_{(2)}
\]

取安全 negative：

\[
q^-_{A,32}
\]

定义：

\[
L_{\text{multi-A}}
=
\operatorname{softplus}
\left(
\frac{q^-_{A,32}+m_A-s^+_{(2)}}{\tau_A}
\right)
\]

含义：

> 不要求所有 future-SA 都进入 Top32，
> 只要求 multi-positive Video history 至少保留第二个 coarse future mode 的竞争力。

默认：

```text
lambda_multi_a = 0.05
```

---

## 16.2 S3 安全条件

若：

```text
|A+| < 2
```

skip。

若：

```text
negative candidates < 32
```

skip。

必须记录：

```text
video_multi_a_active_rate
video_positive_A_count_mean
video_positive_A_count_p95
```

如果发现：

```text
|A+| > 32
```

必须报告，不允许静默假定所有 positive 都可进入单个 Beam32。

# 18. 为什么第一版不显式加入 Global / Transition prior

当前数据确实显示：

```text

Transition Top32 20.50% -> 29.87%

Living:
Global Top32 = 63.16%
```

但普通 SFT 本身已经能从答案频率学 global prior。

第一版如果再同时加入：

```text
Global-head protected negative
Transition protected negative
```

会难以判断收益来自哪里。

新的 behavior allocation 则不同：它直接描述 history evidence 的层级可靠性，
因此已经并入 S2 的 History-Competitive FDR，而不是作为独立 prior trick。

因此：

```text
S1:
不使用 behavior / global / transition，保持纯 novelty-aware TopK。

S2:
加入 hierarchy-aware behavior evidence；
仍不加入 global / transition prior。

S3:
在 S2 基础上只增加 Video Multi-A。
```

Global / Transition prior 若后续需要，再单独开 V4.4 prior-aware experiment。
